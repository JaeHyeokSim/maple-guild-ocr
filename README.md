# maple-guild-ocr

메이플스토리 길드창 **컨텐츠 참여 현황**(닉네임 / 직업 / 레벨 / 직위 / 주간미션 / 지하수로 / 플래그)을 화면 공유나 스크린샷에서 읽어 표로 만드는 정적 웹페이지입니다. OCR은 모두 브라우저 안에서 처리되며 서버로 이미지를 보내지 않습니다.

## 사용법

1. **화면 가져오기**: "메이플 창 공유 시작"(창 → MapleStory 선택), 이미지 열기, Ctrl+V 붙여넣기, 드래그앤드롭 중 하나를 씁니다.
2. **길드원 명단(선택)**: 월드·길드명을 넣고 "명단 불러오기"를 누르면 넥슨 오픈API 명단으로 닉네임을 바로잡고 미캡처 길드원을 알려줍니다. 한 번 조회한 길드는 24시간 캐시되며 "강제 새로고침"으로 다시 조회합니다.
3. **표 영역**: 컨텐츠 참여 현황 표 머리글을 기준으로 자동으로 찾고, 공유 중 창을 옮겨도 따라갑니다. 못 찾으면 첫 행부터 마지막 행까지 드래그합니다.
4. **인식**: "현재 화면 인식"을 누릅니다. 화면 공유 중 "자동 캡처"를 켜 두면 스크롤하는 동안 처음 보는 행만 인식해 합칩니다. 표 끝에서 잘린 행, 한 프레임만 스친 행은 버립니다.
5. 노란 칸을 확인하고 고친 뒤 **기록 저장**, CSV 저장, 엑셀용 복사를 합니다. 저장한 기록은 "비교" 목록에서 골라 지난주와 수로 점수를 비교할 수 있습니다.

## 인식 방식

| 항목 | 방식 |
|---|---|
| 행 분리 | 밝은 글자 픽셀의 가로 투영 |
| 열 분리 | 세로 투영으로 7개 덩어리를 찾아 경계 자동 설정 |
| 숫자(레벨·미션·수로·플래그) | 게임 비트맵 폰트 **템플릿 매칭**(100% 배율 캡처에서 정확). 맞지 않으면 Tesseract로 형식(`123,456`)에 맞을 때까지 배율을 바꿔 재시도 |
| 닉네임 | Tesseract `kor+eng`, `kor` 여러 전처리 중 신뢰도 최고값. 괄호 뒤는 버림 |
| 닉네임 학습 | 직접 고치거나 기록 저장한 닉네임을 글자 이미지 해시와 함께 저장 → 다음 캡처부터 자동 입력 |
| 직업 | Tesseract `kor` + 직업명 사전 보정 (`js/jobs.js`) |
| 접속 여부 | 흰 글자 = 접속, 회색 = 미접속 |

윈도우 배율(DPI)이나 게임 해상도 때문에 화면이 확대·축소되어 캡처되면 숫자 템플릿이 맞지 않아 Tesseract로 넘어가며, 이때는 정확도가 떨어집니다.

## 배포

- **GitHub Pages**: https://jaehyeoksim.github.io/maple-guild-ocr/ — `public/` 폴더를 `gh-pages` 브랜치로 올려 서비스합니다(`npm run deploy:pages`). 서버가 없으므로 길드원 명단은 페이지에서 개인 넥슨 API 키를 입력해 불러옵니다.
- **Cloudflare Workers**(선택): 아래처럼 배포하면 서버 API 키로 키 없이 명단을 불러올 수 있습니다.

## 개발 / 배포

정적 페이지(`public/`)와 넥슨 API 프록시 Worker(`src/worker.js`)로 되어 있으며 빌드 과정이 없습니다.

```bash
npm install
echo NEXON_API_KEY=발급받은키 > .dev.vars   # 로컬용 (선택)
npm run dev      # http://localhost:8787
npx wrangler secret put NEXON_API_KEY        # 배포용 키 등록
npm run deploy   # Cloudflare Workers 배포 (wrangler login 필요)
```

서버 키가 없으면 페이지에서 개인 API 키를 넣어 브라우저가 넥슨 API를 직접 호출합니다(넥슨 API는 CORS 허용).

화면 공유(`getDisplayMedia`)는 HTTPS 또는 localhost에서만 동작합니다.
